# 日常用品扩充验收（2026-11-04）

- 内容：洗漱清洁、出门随身、学习用品、居家用品各12种，共48张介绍卡、96道二选一题，每轮随机6题。
- 图片：48张本地实物照片；逐张检查物品与名称，移除插画及主体不符的候选。保留完整比例，封面与奖励沿用原创插画。来源、作者、许可及SHA-256见 `public/images/daily/sources.json`，课程内可打开署名页。
- 语音：144条用品语音，`afinfo`逐文件读取通过；自动测试核对介绍标题和全文、题干及文本索引的一致性。本次未逐条人工听审全部144条音频。
- 浏览器：本地IAB，390×844手机和820×1180平板尺寸。手机分组按钮2列、卡片2列，无横向溢出；平板分组按钮4列、卡片3列。
- 图片加载：依次切换四组，每组12张图片均complete且naturalWidth>0，共48张通过。
- 互动：点选雨衣为第24/48页、画纸为第33/48页；下一页进入胶棒第34/48页；可返回用品列表并再次选择其他分组。
- 练习：介绍页直接进入找一找，进度1/6至6/6；先选错再改选正确，显示重试反馈及正确反馈；手动继续；完成显示贴纸奖励；再玩一次返回用品列表。
- 校验：`npm test`：4个文件、31项通过；`npm run build`通过；`git diff --check`通过。
- 范围：发布前本地开发版本验收；发布结果以对应提交的GitHub Pages部署记录为准。本次浏览器检查不代表实体手机、平板或微信浏览器验收；静音与后台音频暂停继续复用既有实现，未重新做全场景声音听审。
